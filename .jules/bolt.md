## 2024-05-30 - Caching Expensive Derivations on Immutable Structures
**Learning:** In the Vault UI, calculating the `getVaultSize` requires serializing the entire immutable `PasswordVault` structure (via `JSON.stringify` and `TextEncoder.encode`). Because this was calculated on every `updateUI` call (triggered continuously during actions like typing in the search bar), it blocked the main thread for large vaults. Since the vault itself is immutable (via `Object.freeze`), relying purely on reference equality (`===`) is theoretically sound but often discouraged in standard practices due to potential ecosystem constraints.
**Action:** When calculating expensive derived values from large, technically immutable domain objects, implement caching using a composite key built from explicit state properties (e.g., `vault.metadata.modified` and `vault.entries.length`) rather than recalculating O(N) operations on every render cycle.
